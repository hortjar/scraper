# @scraper/web

Vite + React 19 single-page app. Two products in one bundle: the marketing
landing page and the signed-in console. Built to
[docs/04-FRONTEND.md](../../docs/04-FRONTEND.md) and
[docs/15-DESIGN-SYSTEM.md](../../docs/15-DESIGN-SYSTEM.md).

## Layout

```
src/
  main.tsx                 createRoot only — no providers, no logic
  App.tsx                  the provider stack: Query → i18n → Tooltip → Toast → Router
  router.tsx               createRouter + the Register module augmentation
  routeTree.gen.ts         generated by @tanstack/router-plugin, committed
  routes/
    __root.tsx             document title, <Outlet />
    index.tsx              landing page
    _auth.tsx, _auth/      login, register — AuthShell
    _app.tsx, _app/        dashboard — AppShell
  components/
    ui/                    shadcn-style primitives over Radix (Button, Dialog, …)
    molecules/             one job each (StatusPill, DeltaBadge, RelativeTime, …)
    organisms/             composed, still single-purpose (PulseStrip, DataTable, …)
    layouts/               MarketingShell, AuthShell, AppShell
  features/
    system/                AppStatus — version + connection indicator
  landing/                 hero, steps, notes — landing-only composition
  api/
    generated/             Hey API output — never hand-edited, drift-checked in CI
    runtime-config.ts      baseUrl, credentials, custom fetch
    session-fetch.ts       single-flight 401 refresh, transport errors → ApiError
    index.ts               registers the error interceptor, re-exports the SDK
  lib/
    api/                   error envelope → ApiError, QueryClient factory, error copy
    browser/               THE ONLY useEffect ZONE (see below)
    format/                locale-aware number/date formatting
    utils/                 cn, signal-hue
  stores/                  TanStack Store: preferences (theme, locale), ui (density, diff view)
  i18n/                    i18next instance, namespaced ICU catalogs for en + cs
  styles/                  tokens.css (design tokens), index.css (Tailwind 4 entry)
```

## The API layer is generated

`pnpm gen:api` regenerates `src/api/generated/` from `apps/api/openapi.json`. No
request code is written by hand. Three small modules wrap it, and they are the
reason **features must import from `@/api`, never from `@/api/generated`** — the
barrel is what installs the error interceptor, so a deep import silently loses
`ApiError` mapping.

Generated files carry a `@ts-nocheck` header applied by
`scripts/seal-generated.mjs`. Hey API's runtime is not written for
`exactOptionalPropertyTypes`, which this workspace enables; sealing the vendored
implementation preserves that strictness for our own code while every exported
type stays checked where we use it.

## Three state homes, never a fourth

Per [docs/04-FRONTEND.md §6](../../docs/04-FRONTEND.md):

| State                    | Home                               | Example                       |
| ------------------------ | ---------------------------------- | ----------------------------- |
| Server data              | TanStack Query                     | `healthQueryOptions()`        |
| Cross-route client state | TanStack Store                     | `preferencesStore`, `uiStore` |
| Ephemeral local state    | `useState` in the owning component | a dialog's open flag          |

URL state lives in the route, via TanStack Router search params. Nothing else is a
state container — no context-as-store, no module-level mutable singletons outside
`stores/`.

## `useEffect` is banned, and the ban is mechanical

The `scraper/web-effects` block in `eslint.config.ts` fails the build on `useEffect` and
`useLayoutEffect` anywhere except `src/lib/browser/**`. That directory is the
escape hatch: every genuine subscription to something outside React lives there,
wrapped in a named hook with its own test.

```
lib/browser/
  use-online-status.ts     navigator.onLine + online/offline events
  use-event-listener.ts    the primitive the others build on
  use-interval.ts          setInterval
  use-media-query.ts       matchMedia
  use-hotkey.ts            keydown
  use-document-title.ts    document.title
  document-theme.ts        the class on <html> (not a hook)
```

Feature code imports those hooks. If you reach for `useEffect` in a feature, the
answer is one of: derive it during render, do it in an event handler, use
`useSyncExternalStore`, put it in a Query, or add a hook to `lib/browser` with a
test. In that order.

## Runtime configuration, not build-time

The image is built once and configured per environment. `public/config.js` assigns
`window.__APP_CONFIG__`, is served with no-cache, and is rewritten from env vars
by `deploy/entrypoint.sh` at container start. `src/lib/config.ts` reads it with
literal fallbacks so `pnpm dev` needs no env at all.

`version` and `commit` are the exception — they are baked at build time via
`__APP_VERSION__` / `__GIT_SHA__` defines, because they describe the bundle
itself. Both are surfaced in the UI by `features/system` next to the connection
indicator, satisfying [docs/04-FRONTEND.md §8](../../docs/04-FRONTEND.md).

## Connection status

`useAppStatus` polls `/health` and combines it with `useOnlineStatus`:

- browser offline → `offline`
- query erroring, or `status !== "ok"` → `reconnecting`
- otherwise → `connected`

`deriveConnection` is a pure function and is unit-tested separately from the hook.

## i18n

No literal strings in JSX — `eslint-plugin-i18next` enforces it. Catalogs are
namespaced JSON (`common`, `auth`, `monitors`, `runs`, `channels`, `settings`,
`landing`, `errors`) under `src/i18n/locales/<locale>/`, bundled directly rather
than fetched, and `en` is the source of truth. `pnpm --filter @scraper/web
i18n:types` regenerates the `i18next.d.ts` augmentation that makes `t()` keys
type-checked; `pnpm i18n:check` (root) verifies `cs` has no missing or extra keys.

Locale resolution order: persisted preference → `navigator` → `en`.

## Design tokens

`src/styles/tokens.css` is the only place raw color values appear. Chrome is
monochrome, content is chromatic; machine-generated text is mono (Geist Mono),
human text is sans (Archivo). The 8-hue OKLCH Signal ramp is exposed as CSS
variables and reached from TS through `lib/utils/signal-hue.ts` — components never
hardcode a hue. `grep oklch src/` outside `tokens.css` returns nothing, and it
should stay that way.

Fonts are self-hosted from `public/fonts/`, which currently holds only a
`.gitkeep` — the two `.woff2` files are not in the repo. Until they are dropped
in, the `@font-face` rules fail silently and the stack falls back to
`system-ui` / `ui-monospace`, which is a visual regression but not a broken page.
[`src/assets/fonts/README.md`](src/assets/fonts/README.md) has the exact sources,
licences, and the `pyftsubset` commands used to produce them.

## Local development

```bash
pnpm --filter @scraper/web dev        # :9301, proxies /api to VITE_API_PROXY (default :9300)
pnpm --filter @scraper/web test
pnpm --filter @scraper/web typecheck
pnpm --filter @scraper/web build
```

The dev server needs no backend to render the landing page. The console will show
`reconnecting` until `apps/api` is up.
